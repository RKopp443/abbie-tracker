Live data. This page polls CrossFit's own public leaderboard API. It checks every minute for 45 minutes after each event ends, when scores are actually posting, and every 10 minutes otherwise. No login, no key, works for anyone who opens the file. If the API path changes, edit the API_URL constant at the top of the script block. If the dot goes amber, the page fell back to its baked-in snapshot and you should use the official CrossFit Games leaderboard.

Data caveat. Heat assignments for Events 9-20 are released shortly before each session and are not in the API, so those stay TBD. Event windows and workouts are from the official CrossFit workouts page; four events are still unreleased.
